# 两种基本贪心
### 排序策略
「我们将 XXX 按照某某顺序排序，然后按某种顺序（例如从小到大）选择。」
如果答案与数组元素顺序无关，一般需要**排序**。排序后，可以遍历计算。
##### 如何确定“怎么排”？
做贪心题时，如果你觉得需要排序，可以尝试用 **“邻项交换法” (Exchange Argument)** 在草稿纸上推导一下：
假设有两个相邻的任务 A 和 B。
1.  如果是顺序 **A, B**，总收益是多少？
2.  如果是顺序 **B, A**，总收益是多少？
3.  我们要让 **(A, B) 的收益 > (B, A) 的收益**，需要满足什么不等式？
4.  这个不等式就是你的**排序规则**。
**口诀：**
*   想省时间/空间 $\rightarrow$ **小**的优先 / **短**的优先。
*   想留后路 $\rightarrow$ **结束早**的优先。
*   想拿收益 $\rightarrow$ **性价比**高的优先。
*   搞不清楚 $\rightarrow$ 推导 **A+B vs B+A**。

 [3440. 重新安排会议得到最多空余时间 II](https://leetcode.cn/problems/reschedule-meetings-for-maximum-free-time-ii/) （先处理后选择）
 枚举：
 每个会议两种情况：
 1.能不能放到当前所在空间的外面去，放到外面那当前空间就是一个新的空余空间 
 2.若不能放到空间外面去,那只能移到当前空间的边边,新的空余空间就是左边空余+右边空余
 
 要想放到外面,要求一个空间最大值,把会议放到这个最大空间里
 为什么求最大空间?
	 因为如果最大空间都不能满足,那其他空间更不能满足,会议根本不能放到外面去
 求最大空间:
	 但是,这个空间最大值不一定在外面,可能在当前会议的左右也就是当前会议这个空间里面,那我们就要找第二大空间;但是第二大空间也有可能在在当前会议的左右,那我们求第三大空间,当前会议的左右只有两个空间,第三大空间一定在外面
由于前三大空间是固定的,所以可以先求出来后面重复使用

难点:在怎么写分类讨论卡住了.只需要从能移出去入手,若三大空间有一个能满足,那就能移出去.具体实现:1.左右都不是最大,且最大够塞;2.左右都不是二大,且二大够塞;3.三大够塞

```python
class Solution:  
    def maxFreeTime(  
        self, eventTime: int, startTime: List[int], endTime: List[int]  
    ) -> int:  
        n = len(startTime)  
  
        # 求空间的函数  
        def get(i):  
            if i == 0:  
                return startTime[0]  
            elif i == n:  
                return eventTime - endTime[-1]  
            else:  
                return startTime[i] - endTime[i - 1]  
  
        # 求三大空间  
        maxm, mid, minm = 0, -1, -1  
        for i in range(1, n + 1):  # n个会议，n + 1个空间  
            sz = get(i)  
            if sz > get(maxm):  
                minm = mid  
                mid = maxm  
                maxm = i  
            elif mid < 0 or sz > get(mid):  
                minm = mid  
                mid = i  
            elif minm < 0 or sz > get(minm):  
                minm = i  
  
        ans = 0  
        for i in range(n):  
            sz = endTime[i] - startTime[i]  
            if (  
                (i != maxm and i + 1 != maxm and sz <= get(maxm))  
                or (i != mid and i + 1 != mid and sz <= get(mid))  
                or (sz <= get(minm))  
            ):  
                ans = max(ans, get(i) + get(i + 1) + sz)  
            else:  
                ans = max(ans, get(i) + get(i + 1))  
        return ans
```

# 区间贪心
区间贪心有如下经典问题：

### 不相交区间（区间调度）
（单机器调度/活动安排）：给定一些区间，从中选出尽量多的两两互不相交的区间。
问题：规定时间内，尽可能多的完成任务
- 贪心：最早结束时间优先

区间分组（任务调度/会议室）：给定一些区间，把这些区间分成最少的组，使得每组内的区间互不相交。
区间选点（射气球，Interval Stabbing）：给定一些区间，在数轴上放置最少的点，使得每个区间都包含至少一个点。最少要放置多少个点？
区间覆盖（灌溉花园）：给定一些区间，从中选出尽量少的区间，覆盖一条指定线段 [s,t]。
